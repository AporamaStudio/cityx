# 锁定进攻与可破坏防线

2026-10-09。炮位、瞭望塔选址及夜间加急统一见 [当前P0](plot-economy-and-outposts.md#建筑炮位与瞭望塔p02026-10-08-确定)。原型可运行不代表已经好玩。

## 用户确定的 P0 原则

**敌人先出题，玩家再答题。** 每天确定来源、火光目标、原始路径与出怪参数；普通建设不重新选来源或目标，不比较火力和破墙成本。

- 墙可封路且有HP，敌人只攻击挡住下一格的墙；攻破后下一拍前进。
- 建筑炮位不受击、不维修，建拆不改变建筑原有通行；瞭望塔挑高，地面可通行。
- 只有实际建筑新建或清除会修补绕行。经营恢复、炮位嵌入或瞭望塔建设均不制造绕路。
- 同格同拍同目标合流，HP、满HP和成员数相加；每拍扣一次格子火力。停留也受伤，完全消灭才给成员合计金币。
- 每拍先确定移动/攻墙，再合流和结算炮火，最后汇总存活敌群的攻墙伤害。被炮火消灭的群不再伤墙，同拍顺序不能令敌人提前穿墙。
- 火光受击区是完整3×3特殊广场。敌人进入其中任意格，当拍经炮火结算后的剩余HP一次性造成伤害并退场；无须抵达中央格，也不发击杀奖励。锁定目标仍为火光，原始路径、绕行和路线预告止于首次进入广场的格子。火光归零失败。瞭望塔不进入目标池，也不吸收进攻。
- 破墙保留支出、原址和建造日，次日可维修或拆返；返还和加急规则见P0文档。重试恢复战前布局、路线、支出与HP，撤销本晚补炮、加急费和收益。
- 来袭配置是明确的重新出题工具；普通建设不调用。参数应用保留建筑状态和已发生的支出，不能借调参复制退款。

默认参数见 `src/config.js`。地图须保证建筑都恢复后，仍有道路骨架连接敌源和火光；墙可破，不要求玩家保留无墙通路。墙争取的时间、有限炮位与经济投入是否形成取舍，需要真人试玩。

## v25 路线撤销的实现约束

每天早晨保存当天原始进攻路径；每次建设、清理或拆除，都根据当前仍存在的建筑，从这条原始路径重新计算必要绕行。临时建筑撤销后，其绕行必须撤销，其他建筑造成的绕行仍保留。不比较火力或破墙成本，也不主动把原始路径优化为新的全局捷径。

已修复的坑：在上一次绕行结果上继续修补，会让“当天建造 → 全额退款拆除”永久保留免费绕路。必须保留独立的当天原始路径；重试保留基准与当前路径，次日才重新出题。墙是可破坏路障，炮塔不改变通行图。屋顶炮位保留物理建筑，不因嵌入变成通路；经营用途、启停不触发绕行。
