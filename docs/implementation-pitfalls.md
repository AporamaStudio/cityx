# 实现踩坑记录

记录已定位的问题、根因与防复发约束。实际复现场景和检查结果留在 [验证记录](verification.md)，不在这里重复流水账。

## Canvas改尺寸但GPU雾贴图仍沿用旧存储（2026-10-18）

**现象**：局部/全城、关雾/开雾或雾场对照切换后，云雾错位、显示不全或露出大片未知轮廓；CPU雾场密度和Canvas像素正常，控制台也未必有明确报错。

**根因**：当前Three使用`texStorage2D`分配不可变尺寸的GPU存储，后续同一Source主要走`texSubImage2D`。同一个Canvas被原地缩放，单设`needsUpdate`只更新像素，不能保证旧尺寸纹理重新分配；直接比较`texture.image.width`和Canvas当前宽度也无效，两者指向同一对象。裁剪雾窗口及1×1空雾切换触发此问题。

**防复发**：独立保存上次上传的宽高；尺寸变化先释放GPU存储再上传，同尺寸帧继续复用，不改云纹或信息权限。核查必须包括真实GPU显示，不能只检查CPU采样或shader uniform已开启；覆盖窗口变大、变小、同尺寸平移、局部/全城往返和关雾/开雾。实际入口为`src/city-observation.js`，回归检查在`tests/city-render-cache.test.js`。

## 旋转合批包围盒把整座园区抬离地面（2026-10-18）

**现象**：品质地标接入城市后，建筑连同广场、道路、围栏一起悬空，火车站与城外铁轨错位；原单体预览正常。

**根因**：`Box3.setFromObject`默认将网格局部轴对齐包围盒变换到世界坐标。按材质合批的网格保留首个构件旋转，大包围盒旋转后会虚扩到地下；接入方用`-bounds.min.y`落地、包围盒中心对齐XZ，反而把园区抬高并平移。即使使用精确顶点边界，地下底板也不等于地表零点。模型和地形本身并没有几十米高差。

**防复发**：米制园区须明确制作原点、地表高度及地下基础范围；已约定园区XZ中心/地表Y=0的资产，按该原点放到地块中心，不按整体包围盒最低点落地或自动居中。来源不明的模型先核查锚点，不能套用此约定。旋转合批的包围盒只作保守裁剪；需要精确边界时核查真实变换后顶点，禁止用它推断地表。新增/换态至少检查广场接路、地下基础和铁路接缝，保持真实米制比例。

当前实现：`src/city-landmark-model.js`；12份实际GLB核查与回归检查见[落地修复](city-map-generation.md#品质园区悬空修复2026-10-18)及[验证记录](verification.md#大城品质园区落地修复2026-10-18)。

## 自动缩放与滚动条形成布局循环（2026-10-11）

**现象**：侧栏在内容刚好装得下的窗口高度疯狂抖动。1280×845、第三天完整工具和两行注释下，左栏可用宽度在205/220像素间切换。

**根因**：自动滚动条占宽 → 金币/人口重新缩放 → 资源卡高度变化 → 内容又装得下 → 滚动条消失 → 宽度恢复、字体变大 → 再次溢出。ResizeObserver持续响应，使循环逐帧发生；仅调整观察器触发频率不能解决反馈关系。

**当前处理**：

- 金币与人口保留固定行高，缩小内容不缩小资源卡；预览沿用独立占位。
- 桌面左右栏卡片不受容器剩余高度压缩，超出后正常滚动。
- 两侧栏都保持滚动条占位稳定；采用细滑块和透明轨道，替代常驻宽亮色轨道。右栏虽没有资源自动缩放，也须防止滚动条改变敌群换行与卡片高度。
- 手机布局沿用页面滚动，不预留侧栏轨道。固定高度约束只针对稳定资源行；手册、实验台展开及内容新增仍允许正常增高，不固定整栏高度或裁掉内容。

**防复发**：尺寸观察回调会修改字体、图标或布局时，检查修改是否会反过来改变被观察尺寸或父级溢出。至少测试溢出临界高度上下、注释显隐、最大资源数字与两侧栏折叠展开；同一内容状态下连续采样不应反复切换宽高。不要只在始终溢出的短窗口验证，也不要用隐藏滚动条或吞掉观察器错误掩盖循环。
