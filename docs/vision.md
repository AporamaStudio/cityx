# 视野与动态迷雾

## 当前规则

- 控制区决定建设权限，已探索区保存地形记忆，当前视野决定实时敌人和路线可见性，三者独立。
- 初始镜头仍面向南部，但不再整片揭开 30×30。火光及瞭望塔的控制范围保持可见，外围以圆角边界扩展。
- 默认火光外围 6 格、瞭望塔外围 9 格；白天倍率 1、夜晚 0.6、事件倍率 1。外围距离乘倍率后向上取整，因此默认夜晚分别为 4 格、6 格。倍率只影响外围，不缩小控制区。
- 完好炮塔提供与实际火力范围完全相同的视野，包括方形/菱形与最远格。炮塔视野不受昼夜、事件倍率影响；拆除后撤回该炮塔视野。火力结算不另加侦察条件，所有有效射程格天然可见。
- 医院中心固定揭示 5×5，昼夜不变，地标只显示较大的“医院”，不显示尺寸和“收复目标”；不代表受控或占领。
- 探索可提前发现敌源并记住身份与位置，不因此永久揭示实时周边；首次出兵当天白天起，存活敌源从完整占地边缘向外默认揭示2格（包括角落），昼夜持续可见，不依赖连通视野；当晚停兵用弱化虚线。1×1对应5×5、1×2对应5×6、1×3对应5×7、2×2对应6×6，旋转后揭示区也旋转；地图边缘裁剪。已消灭源头仅保留地形记忆，不持续提供视野。`sourceRevealPadding`在config和实验参数 → 视野同步配置0–10，0只揭示占地。
- 迷雾中的路线与实时敌人隐藏，包括已探索但当前看不见的部分。进攻预告仍保留。跳转预览波次不增加探索；尚未出现的敌源标记与路线不因切换预览而公开。
- 用户确定（2026-10-09）：允许建瞭望塔探索后当天拆除全额退款。拆除立即撤回独占视野，恢复较浓迷雾并保留暗淡地形；其他设施与固定揭示覆盖区仍可见。雾内不显示实时敌人、路线与经营/炮位数字标签，进攻预告保留。
- 云雾分为信息表现与环境云层（2026-10-10，用户确定）：未知城区只画统一低饱和道路及建筑体量，不读取用途、特殊标志、敌源HP或经营状态；已探索但失去视野保留灰化地形，当前控制建筑整栋清晰。保留现有外围视野、医院中心固定揭示、敌源发现/公开例外，不将控制与视野合并，也不改变探索、建设、战斗或安全区算法。未见敌群与路线仍隐藏，已发现敌源标记与HP沿原规则保留。
- 用户修订（2026-10-10）：控制区始终清晰，从整栋归属后的真实控制边界向外 X 格由无雾渐入静态薄雾，再向外 N 格渐入流动浓云，更远处完全遮挡；避免全图都能看见道路与建筑。默认 `fogThinCells=4`、`fogDenseCells=6`，config与实验台“云层”同步暴露，范围均为1–20整数。固定于世界的轻微起伏柔化雾环，青色控制线仍精确；控制建筑整栋无探索雾。内圈只有静态灰蓝薄雾，外圈的两层云纹逐渐增强，白天暖灰白/浅灰蓝、夜晚蓝灰；淡化运动贡献而不局部改变流速。X+N之外有不透明底层，云隙和全城缩放都不露出远处地图。缩放只减弱过渡带的云纹，静态遮蔽不变。
- 云层画在可见敌人、炮塔、墙状态、控制线、路线、建造提示和报价下面；先按既有权限判断信息，再绘制，不能靠缩放/云隙探知新情报。医院固定揭示及已发现敌源标记/HP仍按原例外显示。控制内立即清晰，外围约0.36秒退雾；撤回立即增强遮挡并保留探索记忆，不恢复完全未知。地图外围延续同一距离渐变与云底色；减少动态效果时云静止、退雾立即完成，后台停止额外重绘。本轮不新增天气、侦察玩法或灯光系统。
- 云层流速 `cloudSpeedMultiplier` 在config与实验台“云层”同步暴露，默认1、范围0–3，0静止，支持小数。调速连续累计云纹位移，不改变揭雾时长、视野或战斗速度。白天云层降低高光亮度，页面灰绿背景、暖灰面板表达规划；夜晚深蓝灰与柔白文字表达防守。页面、地图和按钮共用长按及原900毫秒日出进度，经过少量暖暮色；取消沿同一进度约220毫秒回退。环境连续插值，深/浅文字中途换用并加强中间灰度下的对比，云纹连续重复填充避免混合接缝。减少动态偏好下场景直接切换。P0：布局、组件和信息位置不变，只改变明暗、背景与少量氛围；资源、选中和危险含义保持一致，未按满不改变逻辑视野或战斗阶段（2026-10-10，用户确定）。
- 雾外不显示敌人坐标日志、伤害文字及金币飞出位置。金币和预告结果仍按真实战斗结算。
- 实验参数可配置外围距离、昼夜/事件倍率、敌源边缘揭示格数；显示/隐藏迷雾只改变展示，不写探索记录。天气与全图事件本身未实现。
