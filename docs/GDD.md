# cityx09 · 一波防守实验

2026-09-20；第二轮实施基线：根据用户实际试玩反馈加入造墙、墙上炮台与网页调参。用户已授权采用讨论中的简单规则开始实现。数值为实验起点，可在试玩后修改；可运行不等于已验证好玩。

## 要验证的体验

有限预算和墙块下，玩家是否愿意改变路线、安排墙上炮位来提高覆盖？敌群合并是否使汇合前后布防产生有趣差异？受伤直接减少漏怪损失，是否让建设改善容易被感知？

本轮只实现布防 → 一波防守 → 结果 → 保留布局修改重试。完整经营、扩张及逐日成长稍后加入，当前波次不代表约五分钟的完整游戏日。

## 地图与操作

- 30×30、2D 俯视格子；滚轮缩放、拖动平移、按钮恢复全图。
- 一个篝火，默认三个敌人源头。源头数量、坐标、生命、批数、首次出怪节拍及间隔可在准备阶段配置；坐标为 0–29。
- 固定墙和玩家自建墙均不可通行，可架设炮台；敌人不攻击墙或武器。炮台只能放在无其他炮台的墙格上。
- 默认 20 块单格墙，数量独立于炮台预算；不加最小炮台间距，不做形状卡牌或抽卡。固定墙不可拆，自建墙可回收；先拆炮，才能拆其下方自建墙。
- 建墙时即时预览新的共享路线，点击才提交；会封死任意源头通路的放置无效，不消耗墙块。不允许覆盖源头和篝火。拆墙后同样更新路线。
- 四向最短路。从篝火生成共享方向，每格只有一个固定下一格，距离严格下降。所有源头必须可达；非法配置不能开始战斗。
- 路线提前显示；不按敌人来路、火力或身份改道。准备阶段建墙可改变路线，战斗中不修改地形或源头。

## 武器与预算

- 武器 A（近防炮）：占一格，默认方形范围 1、火力 2、价格 10。
- 武器 B（远防炮）：占一格，默认方形范围 3、火力 1、价格 20；以更大覆盖换取更低单格火力。
- 两者形状均可在网页改为菱形。方形按最大轴向距离，菱形按曼哈顿距离；均含中心，地图边界裁切。墙格不可通行，覆盖墙格不会对敌人产生伤害。
- 覆盖火力直接相加，不被墙遮挡。每个格子的火力均独立生效，武器没有跨格总吞吐限制。
- 默认预算 100，按各类型现行价格扣除。建设阶段拆炮全额返还；战斗中不可建造／拆除，也不可应用新参数。暂停只供观察。
- 放置前显示范围与合法性，放置后立即显示覆盖和格子火力。

## 节拍、合并与伤害

默认每 450 毫秒一步，可暂停、单步与加速。不建设通用调度系统。每步顺序：

1. 场上敌人沿共享方向前进一步。
2. 到期源头生成一批敌人，新敌人本步留在源头。
3. 同格敌人合并：剩余生命相加，初始满值相加；血条为剩余值／满值。路线相交但不同步不合并。
4. 每个合并群扣一次所在格火力，伤害不乘成员数。出生算入格；暂停或显示刷新不扣血。
5. 移除生命归零敌人。
6. 抵达篝火的存活群按剩余生命扣除篝火耐久，随后移除。

生命是目前唯一敌人强度数值，不独立设置攻击力。显示当前数值与百分比血条，并突出合并与受伤反馈。默认源头出怪时序安排至少一次自然合并（武器可提前阻止它）。

## 胜负与重复实验

- 默认篝火耐久 30。耐久归零立即失败；所有批次生成完毕、场上无敌人且篝火存活则胜利。
- 保留布局重试：重置敌人、节拍、耐久、统计，预算按保留炮台各自价格重新扣除，同时保留自建墙。清空重来退回全部预算和自建墙配额，保留已应用参数。
- 结果显示耐久、已削减生命、漏过生命及合并次数。快速回到建设，无独立第三操作阶段。
- 参数配置应用后重新开始准备，保留不冲突的武器；不静默删除武器或接受非法配置。

## 网页实验参数

- 可修改初始预算、墙块配额、篝火耐久，以及 A/B 的范围形状、半径、火力与价格。
- 合法输入实时预览覆盖；预算和生命仍显示已应用值。未应用时禁止建造与开战，避免把预览当成生效规则。
- 点击“应用并重置本轮”保留合法布局并重置战斗。新价格导致超预算、新墙配额小于已用量或非法输入均拒绝应用，旧状态不变。
- “取消预览”恢复已应用值；“填入默认值”仅填入草稿，仍需点击应用。刷新恢复 config.js 的默认值，不做配置存档。

## 刻意不做

形状墙块与抽卡、不同移动速度／目标、射速选敌、减速、最小射程、方向武器、经营资源链、存档、主菜单、科技树、自动调参与通用模拟器。

## 验证边界

检查路线可达且汇合后共享后缀、合并守恒、结算顺序、预算与重开、胜负和配置校验，并用浏览器实际操作。数值与真人趣味性留待用户试玩，不以通过测试宣告原型成功。
