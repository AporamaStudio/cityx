# 城市地图生成实验

2026-10-06。独立预览入口 `map-preview.html`，算法 `src/city-map.js`。当前为版本 6。主游戏已经使用同一生成器生成 60×60 城市，接入敌源、建设、经营与十五晚规则；更大尺寸仍只在预览中实验。

## 当前已接入的空间规则

- 固定地块保存几何、身份与临街关系；运行内容独立分为空地、生产废墟、生产建筑、前哨建筑。清理不删除或重切地块。
- 废墟/建筑不可通行、不受击；废墟可修复原类型或免费清理，建筑可拆为空地后换建。
- 空地可通行，可建生产或前哨，也可布置墙/独立塔；整块建筑不能与已有防线叠建。地块内前哨不受击、不失守，以受控点击格为控制中心。
- 道路：普通街道 1 格、主干道 2 格，高速路可保留 3 格；敌人可通行，控制内可造墙和独立塔，主要建筑不能占路。
- 道路与地块直接相邻，内部楼间空隙只是建筑表现。清理后的整块空地才是真实通行空间。
- 每晚来源与火光目标先确定；建筑挡路可就近绕行，玩家墙允许封路、接触后攻击。路线经过的地块仍可正常建设。
- 火光和来源地块保留，不能清理/换建。地块清理和修缮当天即时完成，路线预览同步更新。详情见 [地块经营与前哨](plot-economy-and-outposts.md)。

## 本版生成与表现

1. seed 固定随机序列。相同版本、seed、宽高和主轴宽度得到相同结果。
2. 纵向主轴默认 2 格，可在预览选择 3 格高速路实验；横向普通街道 1 格。主轴按推进段小幅错位，普通街道连接各段。
3. 主轴两侧递归分割成矩形街区，分割线就是 1 格道路。街区填满分配的矩形，不再随机缩小占地后留下无定义空地。地图边缘也明确为道路。
4. 普通街区最小/最大边长可调，默认 2–5，可试 3–6；控件支持 2–8，最小不能超过最大。两边均遵守范围。放不下完整街区的边缘余量明确归道路。尺寸偏好不承诺精确百分比。此前 1×2/2×1 小设施仍未随机生成。
5. 街区用途抽样约 16% 为开放场地，其余建筑街区初始为废墟。比例是助手采用的实验值；起终点额外保证各一个临主路开放街区，不承诺最终比例。
6. 建筑街区用完整占地边界和内部多屋顶表达建筑群；开放场地用绿色底、虚线边界与加号区别于灰色道路。悬停显示整块尺寸、通行和规划建造规则。

输入参数与默认值集中在 `src/map-settings.js`：seed、width/height、mainRoadWidth、minBlock/maxBlock、special、specialMin/specialMax、touching。宽高支持 20–240，主轴宽度支持 2/3；普通边长默认 2–5。预览成功生成后，通过 URL 将当前参数交给主游戏；主游戏可返回相同参数的预览。改变布局会开始新局，不迁移旧设施。战斗目前支持 60×60，其他尺寸的试玩链接隐藏，不静默按另一尺寸接入。

输出 `version: 6`；`blocks` 保存区块几何、`kind`（building/open）和独立 `state`（ruin/null）。`buildings`、`openSpaces` 是同一组区块的分类视图。`tiles` 含 road/block/open，开启自然地形时另含 water；地图 state 与 tiles 是初始状态；运行内容由 `plotContents` 保存，生产投资另有经营记录。当前阻挡集合由内容重建，不改写生成器输出；地图预览只展示初始布局。道路矩形记录层级。跨版本不承诺旧 seed 保留旧图。

## 主游戏外围与镜头（2026-10-08）

- 在可玩地图外绘制 8 格固定景物，按边缘内部道路接续街道，加入低对比楼群、屋顶裂缝和树木，逐渐隐入与迷雾一致的底色。外围无格线、建设、控制、收入或通行数据，不改变生成布局与锁定路线。
- 未探索边缘向外续雾，已探索边缘显示外围；景物不提前透露城内未知地形或未来敌源。日夜各缓存一套配色，跟随昼夜过渡。
- 最小缩放容纳整座城市、两侧各 3 格外围与留白；最大缩放限制单格为 48 CSS 像素。平移最多露出少量外围，地图小于可用视口时按该方向居中。
- 镜头按底部工具实际高度预留空间；窗口尺寸变化保留观察中心和格子大小，全图状态继续适应窗口。“起点”返回起步镜头，“全图”返回最小缩放。当前改动只接入主游戏，生成器预览保持原样。

## 尺度与验证边界

此前检查 cityx09 文档、旧 CityX 项目及个人记忆，没有查到已确定的现实米数。2026-10-08 用户确定每格默认 20 米，可通过 `src/config.js` 的 `DEFAULTS.cellMeters` 修改；实验参数 → 地图可查看、预览和应用该值；此尺度用于右下角比例尺，不改变格子战斗与生成规则。比例尺在缩放按钮右侧，按当前格子像素选择 1/2/5 档距离并同步改变刻度长度。UI 建设与射程继续以格为单位。

可选特殊区块：本轮每张地图最多一个，两边分别处于 specialMin–specialMax（10–30 格）范围；紫色边界、独立身份。优先放在北部主路一侧。空间不足则不生成并在预览提示，不偷偷缩小。暂未赋予医院/车站专属功能。

可选紧邻区块：默认关闭。开启后尝试填掉部分并排建筑之间的一格道路，使两个街区接壤，但保留各自边界、经营身份和普通尺寸上限；不会把开放场地一起封住。每次尝试后检查道路/空地连通，失败就保留道路。不是每个 seed 都保证产生紧邻，预览显示实际组数。该实现是本轮助手采用的保守实验，尚非最终城市生成规则。

## 战斗接入与验证边界

- `city-map.js` 仅产生布局，`map-settings.js` 管理可分享参数；`createCampaign` 接收布局数据，负责将十五晚出生位置放到北部道路。敌人生命、批数和节奏不因地图重写。
- 废墟和建筑占地参与通行寻路，前哨与普通地块建筑统一不可受击。清理出的空地可换建，墙与塔可建道路/空地，仍受控制、资金和昼夜约束。
- 经营支持矩形，整个占地受控才可恢复；任意格操作同一街区。经济采用面积曲线，4×4 为基准，小块回款快、大块产出密度增长后放缓；特殊设施同样计费，不声称已平衡。当天建筑可退款拆除，旧建筑可零退款清理。
- 重试和整局重来保留地图；第一天应用战斗参数也保留地图。旧固定地图只保留为低层战斗回归测试夹具，主页面不再使用。
- 连通、正确结算与十五晚可推进不证明新地图好玩。特别需试玩验证紧邻街区的绕行长度、普通路炮位、特殊设施控制难度以及修缮收益。


## v4 主游戏与探索（2026-10-06）

主游戏默认 60×60，其他尺寸仅供预览；普通路 1 格、主路 2 格，保留 3 格主路实验。seed 和尺寸配置仍独立于战斗波次。正式敌源坐标等待用户确定，目前自动吸附到起步区北缘（y=30–35）的道路。

`starterPlot=true` 在火光附近将一个普通地块缩成受控的 2×2 小废墟，释放的格子归道路。这是普通最小尺寸的显式例外，例如 3–6 仍保留该 2×2 起步地块。地图预览与主游戏共用该设置。

主游戏只显示初始南部 30×30 和后来被控制范围探索过的格子；探索记录独立于当前控制范围，拆除前哨不会遗忘，重开恢复初始迷雾。地图预览展示完整生成结果，不代表玩家已探索；医院已作为左上 10×12 地块加入，占领尚未实现；原北部几何目标仍只作连通预览标记。

`hospital=true` 默认用于主游戏与预览，最小地图 26×26。医院固定 (1,1)、10×12，周围留路，不参与普通尺寸、紧邻合拢或随机特殊设施抽样；`stats.hospital` 独立计数，`stats.special` 仅统计随机特殊设施。

### 起步街区保障（P0）

除显式特殊设计（例如高速路实验）外，街区间只留 1～2 格道路。不得删除与预留区相交的整个街区并把余量变成宽路。起步区先预留完整街区带，再以地块和窄路填满；初始控制区至少包含 2×2 生产、3×3 生产、2×2 住房各一处，允许更多。

## v6 自然地形（2026-10-14）

`MAP_DEFAULTS.nature=true`，2D地图生成提供同名开关并通过URL传递；直接低层生成器默认关闭以保留简单规则夹具。开启后在完整非特殊街区带预留一条约50m宽、略有弯曲的河道，两岸为滨水自然地面；医院、银行、起步保障及目标保留。主轴与少量连接道路架桥，水域加入 `nonTraversable` 固定自然障碍，不允许通行/建设；桥依然是road，原战斗寻路自然绕水过桥，不新增桥梁建造或破坏机制。缺少合适带时不切开特殊地块。

地形保存于 `natural`，3D与俯视回退共用岸线。桥面视觉高差0.8m，人物和地面设施同高；没有坡度射程、航运或安全区特判。最远路线会随新地形改变，默认15晚仍在原160拍内可达。

湖泊和小山优先选远离火光的非特殊原生空地，分别转换为保留自然区。湖面约占原地块宽高的68%，岸线小幅不规则；其覆盖格以保守椭圆包围判为water。小山高度10–15m，以低面数缓坡与混合树群表达，地块为hill固定障碍，不开放山体施工或高低差战斗。剩余平坦河岸/湖岸仍是open地面，可通行并沿原规则建墙/瞭望塔，但没有整块经营地块身份。地形与树群按seed/位置稳定生成，不随昼夜、探索或镜头移动改变。

外围景观现使用 `city-surroundings.js` 的固定无交互描述和 `city-surrounding-model.js` 的合批3D几何，约48格延伸范围；2D回退读取同一描述。城内河道接出地图，四处真实道路出口向郊区自然弯曲；林地成簇、远丘60–82m、少量废墟无运营灯。未知城边雾向外围渐淡，远景按距离融入同一雾底色，没有新增外围权限、格子、敌源或资源。此前8格平面楼群版本仅为历史记录。
