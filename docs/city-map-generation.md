# 城市地图生成实验

2026-10-06。独立预览入口 `map-preview.html`，算法 `src/city-map.js`。当前为版本 3。主游戏已经使用同一生成器生成 30×30 城市，接入敌源、建设、经营与十五晚规则；更大尺寸仍只在预览中实验。

## 当前已接入的空间规则

- 固定地块保存几何、身份与临街关系；运行内容独立分为空地、生产废墟、生产建筑、前哨建筑。清理不删除或重切地块。
- 废墟/建筑不可通行、不受击；废墟可修复原类型或免费清理，建筑可拆为空地后换建。
- 空地可通行，可建生产或前哨，也可布置墙/独立塔；整块建筑不能与已有防线叠建。地块内前哨不受击、不失守，以受控点击格为控制中心。
- 道路：普通街道 1 格、主干道 2 格，高速路可保留 3 格；敌人可通行，控制内可造墙和独立塔，主要建筑不能占路。
- 道路与地块直接相邻，内部楼间空隙只是建筑表现。清理后的整块空地才是真实通行空间。
- 每晚来源与火光目标先确定；建筑挡路可就近绕行，玩家墙允许封路、接触后攻击。路线经过的地块仍可正常建设。
- 火光和来源地块保留，不能清理/换建。地块清理和修缮当天即时完成，路线预览同步更新。详情见 [地块经营与前哨](plot-economy-and-outposts.md)。

## 本版生成与表现

1. seed 固定随机序列。相同版本、seed、宽高和主轴宽度得到相同结果。
2. 纵向主轴默认 2 格，可在预览选择 3 格高速路实验；横向普通街道 1 格。主轴按推进段小幅错位，普通街道连接各段。
3. 主轴两侧递归分割成矩形街区，分割线就是 1 格道路。街区填满分配的矩形，不再随机缩小占地后留下无定义空地。地图边缘也明确为道路。
4. 普通街区最小/最大边长可调，默认 2–5，可试 3–6；控件支持 2–8，最小不能超过最大。两边均遵守范围。放不下完整街区的边缘余量明确归道路。尺寸偏好不承诺精确百分比。此前 1×2/2×1 小设施仍未随机生成。
5. 街区用途抽样约 16% 为开放场地，其余建筑街区初始为废墟。比例是助手采用的实验值；起终点额外保证各一个临主路开放街区，不承诺最终比例。
6. 建筑街区用完整占地边界和内部多屋顶表达建筑群；开放场地用绿色底、虚线边界与加号区别于灰色道路。悬停显示整块尺寸、通行和规划建造规则。

输入参数与默认值集中在 `src/map-settings.js`：seed、width/height、mainRoadWidth、minBlock/maxBlock、special、specialMin/specialMax、touching。宽高支持 20–240，主轴宽度支持 2/3；普通边长默认 2–5。预览成功生成后，通过 URL 将当前参数交给主游戏；主游戏可返回相同参数的预览。改变布局会开始新局，不迁移旧设施。战斗目前只支持 30×30，大地图的试玩链接隐藏，不静默按原大图接入。

输出 `version: 3`；`blocks` 保存区块几何、`kind`（building/open）和独立 `state`（ruin/null）。`buildings`、`openSpaces` 是同一组区块的分类视图。`tiles` 仅含 road/block/open；地图 state 与 tiles 是初始状态；运行内容由 `plotContents` 保存，生产投资另有经营记录。当前阻挡集合由内容重建，不改写生成器输出；地图预览只展示初始布局。道路矩形记录层级。跨版本不承诺旧 seed 保留旧图。

## 尺度与验证边界

此前检查 cityx09 文档、旧 CityX 项目及个人记忆，没有查到已确定的现实米数。20×20 米作为街区表现标尺讨论过，未作为生成或战斗参数；此前 5 米候选不再作为当前推荐。UI 继续以格为单位。

可选特殊区块：本轮每张地图最多一个，两边分别处于 specialMin–specialMax（10–30 格）范围；紫色边界、独立身份。优先放在北部主路一侧。空间不足则不生成并在预览提示，不偷偷缩小。暂未赋予医院/车站专属功能。

可选紧邻区块：默认关闭。开启后尝试填掉部分并排建筑之间的一格道路，使两个街区接壤，但保留各自边界、经营身份和普通尺寸上限；不会把开放场地一起封住。每次尝试后检查道路/空地连通，失败就保留道路。不是每个 seed 都保证产生紧邻，预览显示实际组数。该实现是本轮助手采用的保守实验，尚非最终城市生成规则。

## 战斗接入与验证边界

- `city-map.js` 仅产生布局，`map-settings.js` 管理可分享参数；`createCampaign` 接收布局数据，负责将十五晚出生位置放到北部道路。敌人生命、批数和节奏不因地图重写。
- 废墟和建筑占地参与通行寻路，前哨与普通地块建筑统一不可受击。清理出的空地可换建，墙与塔可建道路/空地，仍受控制、资金和昼夜约束。
- 经营支持矩形，整个占地受控才可恢复；任意格操作同一街区。经济采用面积曲线，4×4 为基准，小块回款快、大块产出密度增长后放缓；特殊设施同样计费，不声称已平衡。当天建筑可退款拆除，旧建筑可零退款清理。
- 重试和整局重来保留地图；第一天应用战斗参数也保留地图。旧固定地图只保留为低层战斗回归测试夹具，主页面不再使用。
- 连通、正确结算与十五晚可推进不证明新地图好玩。特别需试玩验证紧邻街区的绕行长度、普通路炮位、特殊设施控制难度以及修缮收益。
