# cityx09 · 守住火光

可抛弃的 Web 塔防原型。无安装依赖、无构建步骤。

```sh
cd /Users/yhan/cityx_2609
python3 -m http.server 8099 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8099 。不要用 file:// 打开（使用 ES modules）。

墙和炮台只能在蓝色控制边界内建设；边界表示建设权限，敌人仍能进入。先使用建墙工具放置平台，再选择 A/B 炮台架到墙上（也可利用固定墙）。拆炮退款，拆自建墙全额退款；有炮台时先拆炮。滚轮缩放，按住鼠标拖动地图，点击全图复位。第一天准备时可在“实验参数”中直接调整武器形状、范围、火力、价格、资金、墙价、控制半径和篝火耐久；实时预览后应用。超预算布局会拒绝应用。可增删和配置源头；应用后才生效。战斗中及暂停时可在已有墙上补炮，不可造墙、拆除或修复。击杀每个原始敌块获得 1 钱，合并群完全消灭后按成员数奖励，自动入账并播放金币飞向资金栏的动画。重试恢复战前布局和资金，撤销夜间收入与补炮。

规则见 [GDD](docs/GDD.md)。前哨已提供城市扩张；已支持连续三晚；固定生产点与经营结算已实现；塔升级、存档和正式菜单尚未实现。

验证：安装 Node.js 后执行 `npm test`（仅使用内置测试模块，无第三方依赖）。浏览器交互检查记录见 `docs/verification.md`。

实验起点：100 资金、单格墙价 2、控制半径 9 格、篝火 30 耐久；A 方形范围 1／火力 2／价格 10，B 方形范围 3／火力 1／价格 20。默认三晚分别 6／8／9 个敌块，详细数值见 `docs/waves-three-days.md`。参数见 `src/config.js`。页面提供 1×／2×／4×，暂停后可逐拍前进。敌人短距离滑动后结算，合流、扣血与击杀有轻量视觉反馈。切换离开页面会自动暂停；刷新页面会清空本次实验。

前哨实验：左栏选择“前哨”，在现有控制范围内空地建设（25 资金／10 HP／半径 6）。来袭配置可为每个源头选择自动最近目标、火光或指定前哨。失守后变成废墟，只有失去全部覆盖的区域变红；另一前哨仍覆盖的区域保持控制。守住火光后点击“进入第 2 天”或“进入第 3 天”，使用“修复”点击受损火光、前哨或废墟，按缺失 HP 一次修满，默认每 HP 1 钱；悬停查看总价。两者单价可在实验参数中分别调整，资金不足修满时不可修复。资金和受损 HP 延续到下一天，第三晚存活即结束实验。前哨参数可在实验参数中修改。


右栏“来袭预告”可切换三晚的数量、HP、时序、目标与地图路线；虚线 D2/D3 是未来敌源，不能覆盖或封路。各晚建设时可在“来袭配置”调整当晚敌人，不重置生命和资金；开战前必须应用修改。

“重试当晚”恢复该晚开战前状态，不重置前几晚的损伤或收支；进入新一天后未开战时不可重试。“整局重来”恢复第一天初始资金与 HP，清除设施，保留已应用参数和波次；刷新恢复所有默认值。经营收入在守住当晚时自动结算，没有每日补贴。

经营试玩：左栏选择“恢复生产”，点击控制范围内的 ◇ 地点，默认花 10 钱恢复，每晚产出 8 钱。地图共七处，两处在初始控制内。前哨预览显示外围经营机会及额外恢复成本；生产点失控当晚停产，重叠控制仍有效。开始防守前可用拆除撤销新恢复的生产点，经历防守后不可出售。
