# cityx09 · 守住火光

可抛弃的 Web 塔防原型。无安装依赖、无构建步骤。

```sh
cd /Users/yhan/cityx_2609
python3 -m http.server 8099 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8099 。不要用 file:// 打开（使用 ES modules）。

左键放置武器，选择拆除工具退款；滚轮缩放，按住鼠标拖动地图，点击全图复位。准备时可增删和配置源头；应用后才生效。战斗中暂停仅供观察，不允许建设。

规则见 [GDD](docs/GDD.md)。经营、城市扩张、存档和正式菜单不在这一轮范围。

验证：安装 Node.js 后执行 `npm test`（仅使用内置测试模块，无第三方依赖）。浏览器交互检查记录见 `docs/verification.md`。

实验起点：100 预算、10 座武器上限、篝火 30 耐久；源头默认每路 4 批生命 12。参数见 `src/config.js`。页面提供 1×／2×／4×，暂停后可逐拍前进。切换离开页面会自动暂停；刷新页面会清空本次实验。
