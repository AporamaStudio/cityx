# cityx09 · 守住火光

可抛弃的 Web 塔防原型。无安装依赖、无构建步骤。

```sh
cd /Users/yhan/cityx_2609
python3 -m http.server 8099 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8099 。不要用 file:// 打开（使用 ES modules）。

墙和炮台只能在蓝色控制边界内建设；边界表示建设权限，敌人仍能进入。先使用建墙工具放置平台，再选择 A/B 炮台架到墙上（也可利用固定墙）。拆炮退款，拆自建墙全额退款；有炮台时先拆炮。滚轮缩放，按住鼠标拖动地图，点击全图复位。准备时可在“实验参数”中直接调整武器形状、范围、火力、价格、资金、墙价、控制半径和篝火耐久；实时预览后应用。超预算布局会拒绝应用。可增删和配置源头；应用后才生效。战斗中暂停仅供观察，不允许建设。

规则见 [GDD](docs/GDD.md)。前哨已提供城市扩张；收入设施、连续多晚、存档和正式菜单尚未实现。

验证：安装 Node.js 后执行 `npm test`（仅使用内置测试模块，无第三方依赖）。浏览器交互检查记录见 `docs/verification.md`。

实验起点：100 资金、单格墙价 2、控制半径 9 格、篝火 30 耐久；A 方形范围 1／火力 2／价格 10，B 方形范围 3／火力 1／价格 20。源头默认每路 4 批生命 12。参数见 `src/config.js`。页面提供 1×／2×／4×，暂停后可逐拍前进。敌人短距离滑动后结算，合流、扣血与击杀有轻量视觉反馈。切换离开页面会自动暂停；刷新页面会清空本次实验。

前哨实验：左栏选择“前哨”，在现有控制范围内空地建设（20 资金／24 HP／半径 6）。来袭配置可为每个源头选择自动最近目标、火光或指定前哨。失守后变成废墟，只有失去全部覆盖的区域变红；另一前哨仍覆盖的区域保持控制。守住火光后点击“进入次日 · 修复”，使用“修复前哨”花 5 恢复。第二晚暂不开放，可重试第一晚。前哨参数可在实验参数中修改。
