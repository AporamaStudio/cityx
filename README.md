## 手机在线试玩与发布

试玩地址：https://aporamastudio.github.io/cityx/ 。这是独立项目站点，不修改工作室官网。

完整操作见 [发布与手机试玩工作流](docs/publishing.md)。统一入口是 `python3 scripts/publish.py`；`check` 只检查，`publish` 才提交并推送，`status` 查询上线结果。可通过 `$cityx-publish` skill 调用。

继续在本项目开发；仅在用户明确要求发布时提交并推送 `main`。GitHub Actions 会先执行 `npm test`，通过后生成并部署网页。已打开的手机页面需要刷新；页面底部显示发布版本号，刷新会清空本局进度。

`npm run build:pages` 只生成本地 `.pages-dist/`，不会提交、推送或发布。生成目录只包含 HTML、CSS 和游戏 JavaScript；开发文档和测试不会进入网页，但已提交的文件及历史在公开仓库中可见。发布脚本为资源地址添加提交号以更新缓存，并标记试玩页 `noindex`（不等于访问控制）。

首次发布后，需在中国大陆手机上关闭代理，分别用 Wi-Fi 与移动网络测试加载和刷新；线上部署成功不代表当地访问稳定或触控体验已通过验证。

墙和炮台只能在蓝色控制边界内建设；边界表示建设权限，敌人仍能进入。先使用建墙工具放置平台，再选择 A/B 炮台架到墙上（也可利用固定墙）。墙、炮台、前哨与街区当天新建全额拆返，旧设施可零退款清除；有炮台时先拆炮。滚轮缩放，按住鼠标拖动地图，点击全图复位。第一天准备时可在“实验参数”中直接调整武器形状、范围、火力、价格、资金、墙价、控制半径和篝火耐久；实时预览后应用。超预算布局会拒绝应用。可增删和配置源头；应用后才生效。战斗中及暂停时可在已有墙上补炮，不可造墙、拆除或修复。击杀每个原始敌块获得 1 钱，合并群完全消灭后按成员数奖励，自动入账并播放金币飞向资金栏的动画。重试恢复战前布局和资金，撤销夜间收入与补炮。

规则见 [GDD](docs/GDD.md)。前哨已提供城市扩张；已支持连续五晚；固定生产点与经营结算已实现；塔升级、存档和正式菜单尚未实现。

验证：安装 Node.js 后执行 `npm test`（仅使用内置测试模块，无第三方依赖）。浏览器交互检查记录见 `docs/verification.md`。

实验起点：100 资金、单格墙价 2、控制半径 9 格、篝火 30 耐久；A 方形范围 1／火力 2／价格 10，B 方形范围 3／火力 1／价格 20。默认五晚分别 6／8／9／9／9 个敌块，详细数值见 `docs/waves-three-days.md`。参数见 `src/config.js`。页面提供 1×／2×／4×，暂停后可逐拍前进。敌人短距离滑动后结算，合流、扣血与击杀有轻量视觉反馈。切换离开页面会自动暂停；刷新页面会清空本次实验。

前哨实验：左栏选择“前哨”，在现有控制范围内空地建设（25 资金／10 HP／半径 6）。来袭配置可为每个源头选择自动最近目标、火光或指定前哨。失守后变成废墟，只有失去全部覆盖的区域变红；另一前哨仍覆盖的区域保持控制。守住火光后自动进入次日白天，使用“修复”点击受损火光、前哨或废墟，按缺失 HP 一次修满，默认每 HP 1 钱；悬停查看总价。两者单价可在实验参数中分别调整，资金不足修满时不可修复。资金和受损 HP 延续到下一天，第五晚存活即结束实验。前哨参数可在实验参数中修改。


右栏“来袭预告”可切换五晚的数量、HP、时序、目标与地图路线；虚线 D2/D3 是未来敌源，不能覆盖或封路。各晚建设时可在“来袭配置”调整当晚敌人，不重置生命和资金；开战前必须应用修改。

“重试当晚”恢复该晚开战前状态，不重置前几晚的损伤或收支；进入新一天后未开战时不可重试。“整局重来”恢复第一天初始资金与 HP，清除设施，保留已应用参数和波次；刷新恢复所有默认值。经营收入在守住当晚时自动结算，没有每日补贴。

经营试玩：左栏选择“恢复生产”，点击生成街区内任意格。面积 ≤4 格默认花 10、每晚收入 8；更大街区暂用 25 / 20，第一天可分别调参。整块在控制内才能恢复，悬停缺失格标红。任意格真正失控则整块当晚停产，多个控制站可共同保护。建筑街区始终阻路，不能建墙或前哨。当天修缮可全额撤销，旧建筑街区不可清除。

建墙悬停说明路线是否改变；炮台按每次入格伤害，每晚首次合流显示血量加法。右侧“怎样守住火光”可展开查看规则。五晚用于观察投资回报，首次引导与第一晚经营锁定仍待设计。

主按钮统一为“开始夜晚 / 暂停夜晚 / 继续夜晚”；速度使用 1×、2×、4× 独立按钮。重试、整局重来和单步位于右栏后部“重试与测试工具”。可用金币旁的短暂括号是刚刚到账金额，已经计入余额，连续收入会合并提示。

守住后短暂显示胜利并自动入昼；经营收入单独提示来源，金币下方保留昨夜收入卡。停产卡说明失控街区数量与少收金额。击杀行注明夜间已到账，结算不会重复发钱；白天拆建不改写昨夜明细。

地图生成实验：访问 `map-preview.html`，输入 seed、宽高与主轴道路宽度，对比 30×30 和 50×100 等布局。支持缩放、平移和整块占地查看；建筑街区、道路、开放场地分开显示，街区间不留额外空隙。30×30 布局可通过页面链接带入五晚原型。算法与规则边界见 `docs/city-map-generation.md`。


当前城市地图版本：主游戏已经使用 seed 生成地图。顶部“调整地图（新局）”进入预览，设置普通区块边长、特殊区块和紧邻开关后，点击“用这张地图开始五晚试玩”带入同一布局；当前战斗支持 30×30。更大地图仅预览。布局默认值独立放在 `src/map-settings.js`，五晚数值仍在 `src/config.js`。

建筑街区始终阻路，矩形整块恢复，不能建墙架炮；前哨仅可建绿色开放场地。道路与开放场地可建墙架炮但不可彻底封路。当天修缮可撤销，旧建筑街区暂不可清除。以上取代旧固定六块经营点及“不阻路”的说明。
