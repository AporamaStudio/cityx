试玩地址：https://aporamastudio.github.io/cityx/ 。这是独立项目站点，不修改工作室官网。

完整操作见 [发布与手机试玩工作流](docs/publishing.md)。统一入口是 `python3 scripts/publish.py`；`check` 只检查，`publish` 才提交并推送，`status` 查询上线结果。可通过 `$cityx-publish` skill 调用。

继续在本项目开发；仅在用户明确要求发布时提交并推送 `main`。GitHub Actions 会先执行 `npm test`，通过后生成并部署网页。已打开的手机页面需要刷新；页面底部显示发布版本号，刷新会清空本局进度。

`npm run build:pages` 只生成本地 `.pages-dist/`，不会提交、推送或发布。生成目录只包含 HTML、CSS 和游戏 JavaScript；开发文档和测试不会进入网页，但已提交的文件及历史在公开仓库中可见。发布脚本为资源地址添加提交号以更新缓存，并标记试玩页 `noindex`（不等于访问控制）。

首次发布后，需在中国大陆手机上关闭代理，分别用 Wi-Fi 与移动网络测试加载和刷新；线上部署成功不代表当地访问稳定或触控体验已通过验证。

## 当前玩法：锁定进攻与可破坏防线

白天开始时确定来源、火光目标与初始路线。建筑挡路可就近绕行，墙仍接触后攻击；来源和目标不随建设变化。墙拖时间，塔杀敌，瞭望塔占地并扩张控制；允许真正堵住道路。

- **建墙**：基础地面控制内道路/开放场地放置一格墙，不能借建筑整体归属向外延伸。默认 2 钱、12 HP；敌人撞墙停下攻击，攻破后沿原路线继续。墙废墟不阻路，投资不退款，次日可维修。
- **近防炮/远防炮**：只建在受控建筑原始临街边缘，无HP、不受击、不改路；容量为原始面积三分之一向下取整、至少1。近防炮10金币/范围1/火力2，远防炮20金币/范围3/火力1。夜间金币和清场用工默认各×2，实验参数可调。
- **瞭望塔**：第3天起白天可建，在基础地面控制内的道路、空地或自然地面独立部署；挑高可通行，不受击。默认25金币、控制半径6、彼此最小间距4格，参数可调；不占建筑炮位容量。
- **恢复生产**：点击建筑街区任意格恢复整块，基础范围碰到物理建筑至少一格即整栋受控，控制线绕完整建筑；归属不传播到外侧道路或邻栋。按当前默认面积报价：2×2 花 5、每晚 +2；4×4 花 32、每晚 +8；5×5 花 76、每晚 +19。小块快回款，大块持续产出高。空地也可新建生产，但须逐格完整受控；实际新建/拆除物理建筑时敌人绕行，恢复用途和启停不改变通行。守住后自动结算经营，击杀金币夜间已到账。
- **修复**：白天修满火光或墙，悬停看报价；火光默认每HP 1金币，墙按缺失比例×造价50%向上取整。炮位和瞭望塔无须维修。
- **拆除**：白天基价当天全返，旧投入默认返50%；夜间加急费不退。有炮建筑必须先拆炮才能清除；瞭望塔先解除外围依赖。清废墟免费、占当天人力，建筑拆后可换经营用途。

火光归零才是整局失败。战略目标伤害暂沿用敌群抵达火光时按剩余 HP 结算一次；保留同格、同拍、同目标合流，整群被炮火消灭后按原始成员数 × 每人 2 金币发奖励。敌人只攻击挡住下一格的墙，默认每个成员每拍伤害1；不攻击炮位。

`src/config.js` 的 `WAVES` 配置主游戏各晚各来源的敌人 HP；`DEFAULTS.enemyPower` 配置每个成员每拍拆墙伤害，`killReward` 配置固定击杀金币，`productionCostPerCell` / `productionIncomePerCell` 配置 4×4 基准每格成本与收入，`PRODUCTION_CURVE` 配置面积曲线。参数面板可改攻击力、击杀奖励与基准单价，曲线参数在配置文件中调整；来袭配置可改当晚来源 HP，目标固定为火光。维修比例表示完全损坏时维修费占造价的比例，部分受损再乘缺失 HP 比例，并向上取整。

夜间可暂停、1×/2×/4×或单步，只可在合法建筑炮位加急架炮；不能造墙、维修、扩张或拆除。离开页面自动暂停。守住后自动入昼，十五晚后结束；重试恢复战前布局与支出，整局重来保留参数和地图，刷新恢复默认值，无存档。

右栏预告：当晚来源与目标已锁定，未来晚上仅显示暂定路线。实线是场上剩余路线，虚线是后续批次的当前路线；路线经过墙表示敌人会撞墙。来袭配置的“重新出题并应用”是显式实验工具，普通建设不重出题；瞭望塔始终不进入目标池。全局实验参数仅第一天可改。

棋盘内右键取消当前工具，回到浏览状态：悬停查看、拖动平移，左键不建设或拆除；重新选择左侧工具即可继续。滚轮缩放，最远为全图与少量外围，最近每格 48 像素；− / ＋ 右侧比例尺随缩放更新，每格默认 20 米（`src/config.js` 的 `DEFAULTS.cellMeters`，实验参数 → 地图可调）；拖动到边缘会停住，较短方向居中，并为底部控件留出空间。“起点”返回起步区域，“全图”查看整幅地图与迷雾。外围街道、楼群和树木只作景物，向远处雾化，不可建设或通行。顶部“调整地图（新局）”进入 `map-preview.html`；seed、普通街区边长、特殊区块与紧邻开关可分享。主游戏目前支持 60×60，其他尺寸只预览；改变布局开始新局。

## 声音

页首「声音」提供独立音乐／音效开关与音量，白天和夜晚随时可调，浏览器本地记住选择；重试和调参不改变声音偏好。首次默认都开，音乐与音效均为 50%，首次点击或按键后才播放。页面切到后台自动静音，回来后恢复；夜晚仍按原规则保持暂停。

本轮采用原创 Web Audio 合成配乐：白天稀疏旋律、柔和铺底（72 BPM），夜晚独立采用低音、紧张和声与密集短促节奏（108 BPM），平滑切换。开始夜晚播放下沉的落日声；夜战胜利先收住配乐，真正进入次日时播放缓慢展开的暖色和弦，通关也播放天亮声。暂停收起节奏，音乐不随 2×/4×加速。建设成功、击杀与实际金币入账分别有音效，密集击杀合并反馈；经营到账与拆除退款也播放金币声。声音独立于金币结算、迷雾和减少动态效果设置，不下载外部音频。当前编曲用于试玩，听感仍可换。

开发入口：`src/model.js` 为锁定进攻与结算，`src/app.js` 为画面和交互，`src/audio.js` 为声音与原创合成编曲，`src/city-map.js` 为布局，`src/config.js` 为战斗数值，`src/map-settings.js` 为地图参数。当前机制见 [GDD](docs/GDD.md)，本轮实现边界见 [锁定进攻](docs/locked-defense.md)，地块设计见 [地块经营与瞭望塔](docs/plot-economy-and-outposts.md)，浏览器检查见 [verification](docs/verification.md)。

安装 Node.js 后执行 `npm test`（使用内置测试模块，无第三方依赖）。第一天纯塔防，第二天经营，第三天瞭望塔；早晨显示解锁提示。完整引导继续迭代；平衡、扩张动机与好玩需实际试玩，技术检查不代表好玩。

初始南部 30×30 可见，瞭望塔控制范围揭开迷雾，已探索区域保持可见。起步有默认 5 金币恢复、每晚 +2 的 2×2 废墟。页首医院与敌源目标尚未实现，正式敌源坐标待定；十五晚结束只代表防守测试结束。待办见 `docs/todo.md`。
