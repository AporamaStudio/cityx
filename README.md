## 手机在线试玩与发布

试玩地址：https://aporamastudio.github.io/cityx/ 。这是独立项目站点，不修改工作室官网。

完整操作见 [发布与手机试玩工作流](docs/publishing.md)。统一入口是 `python3 scripts/publish.py`；`check` 只检查，`publish` 才提交并推送，`status` 查询上线结果。可通过 `$cityx-publish` skill 调用。

继续在本项目开发；仅在用户明确要求发布时提交并推送 `main`。GitHub Actions 会先执行 `npm test`，通过后生成并部署网页。已打开的手机页面需要刷新；页面底部显示发布版本号，刷新会清空本局进度。

`npm run build:pages` 只生成本地 `.pages-dist/`，不会提交、推送或发布。生成目录只包含 HTML、CSS 和游戏 JavaScript；开发文档和测试不会进入网页，但已提交的文件及历史在公开仓库中可见。发布脚本为资源地址添加提交号以更新缓存，并标记试玩页 `noindex`（不等于访问控制）。

首次发布后，需在中国大陆手机上关闭代理，分别用 Wi-Fi 与移动网络测试加载和刷新；线上部署成功不代表当地访问稳定或触控体验已通过验证。

## 当前玩法：锁定进攻与可破坏防线

白天开始时确定来源、火光目标与初始路线。建筑挡路可就近绕行，墙仍接触后攻击；来源和目标不随建设变化。墙拖时间，塔杀敌，前哨占地并扩张控制；允许真正堵住道路。

- **建墙**：控制内道路/开放场地放置一格墙。默认 2 钱、12 HP；敌人撞墙停下攻击，攻破后沿原路线继续。墙废墟不阻路，投资不退款，次日可维修。
- **近防炮/远防炮**：独立建在道路/开放场地，不能与墙叠建。默认 A：10 钱、10 HP、范围 1、每拍火力 2；B：20 钱、12 HP、范围 3、每拍火力 1。停留中的敌群每拍也受伤；炮塔损坏停火，位置与投资保留。
- **前哨**：在空地地块内选一个受控格驻扎，占用整块地。默认 25 钱、范围 6；立即扩张，不受击、不失守。废墟或旧建筑可先清理，再换建；前哨不能建道路上。
- **恢复生产**：点击建筑街区任意格恢复整块，全部占地受控才允许。按面积平滑报价：2×2 花 20、每晚 +4；4×4 花 128、每晚 +16；5×5 花 304、每晚 +38。小块快回款，大块持续产出高。空地也可新建生产，建筑挡路时敌人绕行。守住后自动结算经营，击杀金币夜间已到账。
- **修复**：次日一次修满火光、墙或塔；火光默认每 HP 1 钱，墙/塔按缺失 HP 比例 × 造价 50% 向上取整。前哨无需维修，悬停查看报价。
- **拆除**：当天建设全额撤销，旧墙/塔/前哨/生产建筑零退款清除；废墟免费清理，地块建筑拆后为空地，可换建。前哨须先解除外围控制依赖；火光及来源地块保留。

火光归零才是整局失败。战略目标伤害暂沿用敌群抵达火光时按剩余 HP 结算一次；保留同格、同拍、同目标合流，整群被炮火消灭后按原始成员数 × 每人 2 金币发奖励。敌人近战攻击墙/塔默认每批每拍 1，不因塔 DPS 高而远距离优先拆塔。

`src/config.js` 的 `WAVES` 配置主游戏各晚各来源的敌人 HP；`DEFAULTS.enemyPower` 配置每个成员每拍拆墙/塔伤害，`killReward` 配置固定击杀金币，`productionCostPerCell` / `productionIncomePerCell` 配置 4×4 基准每格成本与收入，`PRODUCTION_CURVE` 配置面积曲线。参数面板可改攻击力、击杀奖励与基准单价，曲线参数在配置文件中调整；来袭配置可改当晚来源 HP，目标固定为火光。维修比例表示完全损坏时维修费占造价的比例，部分受损再乘缺失 HP 比例，并向上取整。

夜间可暂停、1×/2×/4×或单步，可在控制内独立补炮；不能造墙、维修、扩张或拆除。离开页面自动暂停。十五晚之间资金和损伤延续，守住后自动入昼，第十五晚结束。重试恢复该晚开战前题目、HP、资金与布局；整局重来保留地图、参数和波次配置，刷新恢复默认值，无存档。

右栏预告：当晚来源与目标已锁定，未来晚上仅显示暂定路线。实线是场上剩余路线，虚线是后续批次的当前路线；路线经过墙表示敌人会撞墙。来袭配置的“重新出题并应用”是显式实验工具，普通建设不重出题；前哨始终不进入目标池。全局实验参数仅第一天可改。

滚轮缩放、拖动平移、“起点”返回起步区域、“全图”查看整幅地图与迷雾。顶部“调整地图（新局）”进入 `map-preview.html`；seed、普通街区边长、特殊区块与紧邻开关可分享。主游戏目前支持 60×60，其他尺寸只预览；改变布局开始新局。

开发入口：`src/model.js` 为锁定进攻与结算，`src/app.js` 为画面和交互，`src/city-map.js` 为布局，`src/config.js` 为战斗数值，`src/map-settings.js` 为地图参数。当前机制见 [GDD](docs/GDD.md)，本轮实现边界见 [锁定进攻](docs/locked-defense.md)，地块设计见 [地块经营与前哨](docs/plot-economy-and-outposts.md)，浏览器检查见 [verification](docs/verification.md)。

安装 Node.js 后执行 `npm test`（使用内置测试模块，无第三方依赖）。第一天纯塔防，第二天经营，第三天前哨；早晨显示解锁提示。完整引导继续迭代；平衡、扩张动机与好玩需实际试玩，技术检查不代表好玩。

初始南部 30×30 可见，前哨控制范围揭开迷雾，已探索区域保持可见。起步有默认 20 金币恢复、每晚 +4 的 2×2 废墟。页首医院与敌源目标尚未实现，正式敌源坐标待定；十五晚结束只代表防守测试结束。待办见 `docs/todo.md`。
