## 手机在线试玩与发布

试玩地址：https://aporamastudio.github.io/cityx/ 。这是独立项目站点，不修改工作室官网。

完整操作见 [发布与手机试玩工作流](docs/publishing.md)。统一入口是 `python3 scripts/publish.py`；`check` 只检查，`publish` 才提交并推送，`status` 查询上线结果。可通过 `$cityx-publish` skill 调用。

继续在本项目开发；仅在用户明确要求发布时提交并推送 `main`。GitHub Actions 会先执行 `npm test`，通过后生成并部署网页。已打开的手机页面需要刷新；页面底部显示发布版本号，刷新会清空本局进度。

`npm run build:pages` 只生成本地 `.pages-dist/`，不会提交、推送或发布。生成目录只包含 HTML、CSS 和游戏 JavaScript；开发文档和测试不会进入网页，但已提交的文件及历史在公开仓库中可见。发布脚本为资源地址添加提交号以更新缓存，并标记试玩页 `noindex`（不等于访问控制）。

首次发布后，需在中国大陆手机上关闭代理，分别用 Wi-Fi 与移动网络测试加载和刷新；线上部署成功不代表当地访问稳定或触控体验已通过验证。

## 当前玩法：锁定进攻与可破坏防线

白天开始时确定来源、火光目标与初始路线。建筑挡路可就近绕行，墙仍接触后攻击；来源和目标不随建设变化。墙拖时间，塔杀敌，瞭望塔占地并扩张控制；允许真正堵住道路。

- **建墙**：基础地面控制内道路/开放场地放置一格墙，不能借建筑整体归属向外延伸。默认 2 钱、12 HP；敌人撞墙停下攻击，攻破后沿原路线继续。墙废墟不阻路，投资不退款，次日可维修。
- **近防炮/远防炮**：只建在受控建筑原始临街边缘，无HP、不受击、不改路；容量为原始面积三分之一向下取整、至少1。近防炮10金币/范围1/火力2，远防炮20金币/范围3/火力1。夜间金币默认×2，工具栏显示原价+加急费（10+10、20+20）；架炮和清理废墟均不额外占用人口；金币加急倍率可调。占经营面积带来的住房人口、生产用工与收入变化仍保留。
- **瞭望塔**：第3天起白天可建，在基础地面控制内的道路、空地或自然地面独立部署；挑高可通行，不受击。默认25金币、持续用工1人、控制半径6、彼此最小间距2格，参数可调；不占建筑炮位容量。
- **恢复生产**：点击建筑街区任意格恢复整块，基础范围碰到物理建筑至少一格即整栋受控，控制线绕完整建筑；归属不传播到外侧道路或邻栋。按当前默认面积报价：2×2 花 5、每晚 +2；4×4 花 32、每晚 +8；5×5 花 76、每晚 +19。小块快回款，大块持续产出高。空地也可新建生产，但须逐格完整受控；实际新建/拆除物理建筑时敌人绕行，恢复用途和启停不改变通行。守住后自动结算经营，击杀金币夜间已到账。
- **敌源肃清**：默认8个据点，四种形状且条形可旋转；探索可提前发现，首次出兵当天不论距离自动揭示，发现不激活。地图只显示盾牌+剩余HP；当晚出兵用实线闪烁红边及外溢，不出兵用弱化虚线，不显示等级、血条或首次日期。将基础地面控制推进至出兵口，在周边建筑架炮；夜间炮塔先打敌人，空闲时自动清源。大型源头共用HP，每炮每拍只命中一次；HP归零留下残骸、本晚批次继续、后续永久停兵，其他源头不增强。每格HP范围默认12–30，2×2为48–120；同城耐久抽样固定，每夜回复默认0，均在实验台 → 参数调整 → 敌源可调。每晚固定160拍（nightTicks可调），1倍×450ms名义72秒；到点末拍照常结算，篝火存活则敌人撤退，不伤火光也不发击杀钱；清空且全部批次已出后，仍能清源则自动至少2倍逐拍结算（nightCleanupSpeed可调，1关闭），完全无战斗才跳过余下空闲等待到黎明。进度只显示时间百分比。专用定向武器后续讨论。
- **修复**：白天修复火光或墙；选中后悬停，按钮和金币总数旁同步预览实际扣款，火光HP旁显示恢复量、生命条以条纹预览新增段。预览不改变真实资源；取消悬停即隐藏。火光默认每HP 5金币，按余额购买整数HP、上限为缺失HP，保留零头；不足1HP费用时不扣钱。墙仍一次修满，墙按缺失比例×造价50%向上取整。没有受损目标或当前金币无法执行任何修复时，按钮灰掉并退出修复工具；有可负担的墙维修时仍可用。炮位和瞭望塔无须维修。
- **拆除**：白天基价当天全返，旧投入默认返50%；夜间加急费不退。有炮建筑必须先拆炮才能清除；瞭望塔先解除外围依赖。清废墟免费、不占人口，建筑拆后可换经营用途。

火光归零才是整局失败。每次受击时地图短暂泛红；低于可配置阈值（默认30% HP）时，侧栏与地图火光缓慢闪烁、地图边缘泛红；减少动态偏好改为常亮提示。归零弹出中央失败结算，显示守住夜晚、累计击杀和两类累计金币，可重试当晚、整局重来或查看战场；失败当晚不发经营收入，重试撤销本晚收支与成果。火光受击范围为完整3×3特殊广场，敌人进入任意格当拍先受炮火，再按剩余HP结算一次伤害后退场，不必走到中央篝火格。路线预告止于广场入口，抵达不发击杀奖励；保留同格、同拍、同目标合流，整群被炮火消灭后按原始成员数 × 每人 2 金币发奖励。敌人只攻击挡住下一格的墙，默认每个成员每拍伤害1；不攻击炮位。

`src/enemy-sources.js` 配置默认地图八个据点及其独立十五晚兵力；`src/config.js` 的 `WAVES` 保留旧规则地图波次；`DEFAULTS.campWarningPercent` 配置危急提示阈值百分比（0关闭），`campRepairCost` 配置每HP修复金币，这两项均可在实验面板调整；`DEFAULTS.enemyPower` 配置每个成员每拍拆墙伤害，`killReward` 配置固定击杀金币，`productionCostPerCell` / `productionIncomePerCell` 配置默认 4×4 基准每格新建成本与收入；`renovationCostPercent` 为原用途修缮价占新建价的百分比（默认50%）。面积曲线四项参数也在 `DEFAULTS` 中，均已接入实验参数面板，连同移动节拍可直接调试；来袭配置分地图据点与每晚出兵：据点可增删、改位置/形状/HP并应用为新局，出兵按夜晚编辑敌源编号、敌人HP、批数与节奏；恢复默认值填回当前城市的默认据点和15晚计划，应用并重开生效，保留其他实验参数。敌人出生与路线从源头占地内起始，临街出口仅负责走上道路，不开放建筑通行。维修比例表示完全损坏时维修费占造价的比例，部分受损再乘缺失 HP 比例，并向上取整。

白天长按“结束白天”确认入夜，默认1秒；松开、移出按钮、Esc或切后台取消，按钮由日色经落日转为夜色。键盘可按住空格/Enter；时长在config的 `dayEndHoldMs` 与实验台 → 日夜操作同步可调（300–3000毫秒）。夜间暂停/继续仍是单击，配短促机械开关声；不能入夜时播放低沉短音并在顶栏解释原因。夜晚按钮的月亮随时间进度下沉、临近黎明微亮，暂停冻结；空闲夜末快速走满后，在原有900毫秒停留内太阳升起，复用白天组件，终点与未按下的白天按钮完全一致。

夜间可暂停、1×/2×/4×或单步，只可在合法建筑炮位加急架炮；不能造墙、维修、扩张或拆除。离开页面自动暂停。守住后自动入昼，十五晚后结束；重试恢复战前布局与支出，整局重来保留参数和地图，刷新恢复默认值，无存档。

右栏预告：当晚来源与目标已锁定，未来晚上仅显示暂定路线。悬停或触摸选择预告敌源会高亮地图对应据点；悬停地图敌源会高亮今晚对应预告行，移开解除悬停。实线是场上剩余路线，虚线是后续批次的当前路线；路线经过墙表示敌人会撞墙。来袭配置的“应用本晚”是显式实验工具，编辑当晚才重锁该晚进攻，编辑未来晚不改变今晚；普通建设不重出题。瞭望塔始终不进入目标池。全局实验参数仅第一天可改。

棋盘内右键取消当前工具，回到浏览状态：悬停查看、拖动平移，左键不建设或拆除；小格线与地面棋盘色差隐藏，地块轮廓和控制边界保留。只有选择塔防、经营与扩张或通用栏中的具体工具时恢复格网。滚轮缩放，最远为全图与少量外围，最近每格 48 像素；− / ＋ 右侧比例尺随缩放更新，每格默认 20 米（`src/config.js` 的 `DEFAULTS.cellMeters`，实验台 → 参数调整 → 地图可调）；拖动到边缘会停住，较短方向居中，并为底部控件留出空间。“起点”返回起步区域，“全图”查看整幅地图与迷雾。外围街道、楼群和树木只作景物，向远处雾化，不可建设或通行。顶部“调整地图（新局）”进入 `map-preview.html`；seed、普通街区边长、特殊区块与紧邻开关可分享。主游戏目前支持 60×60，其他尺寸只预览；改变布局开始新局。

## 路线校验

实验台 → 场景与测试 → **校验无墙到达**：读取已应用参数和当前建筑空间，逐晚检查活动敌源的每批出兵；显示最远路程、末批出生/到达拍数、剩余拍数及超时人数。出生当拍不移动，进入火光3×3任意格即到达，最后一拍到达仍有效。忽略玩家墙、炮火和合流；当晚保留锁定路线，其余晚按当前地形与存活敌源估计，不预测未来清源或复原历史战况。打开报告暂停夜晚，关闭后手动继续。默认地图最远69步（路径含起终点70格），末批最晚第142拍到达，160拍无超时；80拍会有57/150个敌人超时。

## 声音

页首「声音」提供独立音乐／音效开关与音量，白天和夜晚随时可调，浏览器本地记住选择；重试和调参不改变声音偏好。首次默认都开，音乐与音效均为 50%，首次点击或按键后才播放。页面切到后台自动静音，回来后恢复；夜晚仍按原规则保持暂停。

本轮采用原创 Web Audio 合成配乐：白天稀疏旋律、柔和铺底（72 BPM），夜晚独立采用低音、紧张和声与密集短促节奏（108 BPM），平滑切换。长按时暖音和风声随时长下沉，白天配乐轻收；取消则淡出并恢复日间配乐，蓄满播放低频落日闷响并切入夜间配乐；空闲夜末先淡出配乐，普通夜战结束时随日出播放缓慢展开的暖色和弦，通关也播放天亮声。暂停收起节奏，音乐不随 2×/4×加速。篝火受击采用更强的低频冲击、碎裂与塌落尾音，仍遵循音效音量和限幅。建设成功、击杀与实际金币入账分别有音效，密集击杀合并反馈；经营到账与拆除退款也播放金币声。声音独立于金币结算、迷雾和减少动态效果设置，不下载外部音频。当前编曲用于试玩，听感仍可换。

开发入口：`src/model.js` 为锁定进攻与结算，`src/app.js` 为画面和交互，`src/audio.js` 为声音与原创合成编曲，`src/city-map.js` 为布局，`src/config.js` 为战斗数值，`src/map-settings.js` 为地图参数。当前机制见 [GDD](docs/GDD.md)，本轮实现边界见 [锁定进攻](docs/locked-defense.md)，地块设计见 [地块经营与瞭望塔](docs/plot-economy-and-outposts.md)，浏览器检查见 [verification](docs/verification.md)。

安装 Node.js 后执行 `npm test`（使用内置测试模块，无第三方依赖）。第一天纯塔防，第二天经营，第三天瞭望塔；早晨显示解锁提示。完整引导继续迭代；平衡、扩张动机与好玩需实际试玩，技术检查不代表好玩。

初始镜头面向南部，实际可见区由当前视野决定，已探索地形保留暗淡记忆。起步有默认 5 金币恢复、每晚 +2 的 2×2 废墟。敌源肃清已实现，医院占领与最终胜利仍未实现；十五晚结束只代表当前实验结束。待办见 `docs/todo.md`。
